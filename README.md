# Hospital Management & Analytics System

## Project Overview
The Hospital Management & Analytics System is a database and data visualization project developed to manage hospital data and analyze important hospital operations. It uses Oracle SQL, PL/SQL, Power BI, and DAX to organize data and present meaningful insights through interactive dashboards.

## Technologies Used
- **Database:** Oracle SQL
- **Programming:** PL/SQL
- **Data Visualization:** Microsoft Power BI
- **Analytics:** DAX

## Project Modules
- Patient Management
- Doctor and Department Management
- Appointment Management
- Treatment and Lab Report Management
- Prescription Management
- Billing and Payment Analysis

## Power BI Dashboards
The project includes four dashboard pages:

1. Hospital Management & Analytics Dashboard
2. Patient & Appointment Analysis
3. Billing & Payment Analysis
4. Treatment & Lab Analysis

## Project Files
- **SQL/** – Contains SQL scripts used for database creation, sample data, queries, and other database operations.
- **PowerBI/** – Contains the Power BI dashboard file and related documentation.
- **page 1.png to page 4.png** – Dashboard screenshots.

## Key Features
- Organizes hospital-related data in a relational database.
- Uses SQL queries to retrieve and analyze information.
- Uses PL/SQL for database programming.
- Presents hospital data through Power BI dashboards.
- Uses DAX measures for analytical calculations and reporting.

## How to Use
1. Download or clone this repository.
2. Run the SQL scripts in Oracle SQL Developer after checking the database setup requirements.
3. Open the Power BI file using Power BI Desktop.
4. Configure the database connection if required to refresh the reports.
